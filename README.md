# Chatbot Query Interface

A clean, responsive chatbot interface built with React, Vite, and Material UI.

## Features

- Clean chat UI with Material Design
- Message history persistence using sessionStorage
- Auto-scroll to latest message
- Markdown support for rich text formatting
- Suggested prompts sidebar
- Responsive layout (sidebar hides on mobile)
- Loading indicators
- Clear chat history button

## Tech Stack

- React 18
- Vite (build tool)
- Material UI (UI components)
- React Markdown (markdown support)
- sessionStorage (chat history persistence)

## Setup

1. Clone the repository
2. Install dependencies:
   npm install
